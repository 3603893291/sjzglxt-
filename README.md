# 三角洲行动胜者为王战队管理系统

基于 **ThinkPHP 8 + PHP 8.1 + Nginx + MySQL 5.7** 的多租户游戏战队管理系统（部分内容由AI生成）。
主域名根路径是「战队入驻平台」，每个战队入驻后获得一个独立目录站点 `/{目录}/`，共用一套代码与一个数据库，数据行级隔离。

## 多租户架构

- **目录制多租户**：主域名根路径（如 `https://你的域名/`）是入驻平台控制台；
  每个战队站点位于 `/{目录}/`（如 `/myteam/`），目录即战队身份，无需二级域名。
- **单库共享 + 行级隔离**：所有租户数据在同一个数据库中，靠 `tenant_id` 字段隔离；
  模型层带租户全局作用域（`BelongsToTenant`），A 战队无法登录、也无法按 ID 读到 B 战队的数据。
- **两套独立账号体系**：
  - `platform_users` 表 —— 入驻平台账号（平台超管 + 想入驻的战队申请人）；
  - `users` 表 —— 各战队站点内的成员账号（带 `tenant_id`），与平台账号互不相通。
- **站点生命周期**：入驻审核通过后自动开通（建战队超管 + 默认设置）；平台超管可随时
  暂停 / 恢复 / 停用某战队站点，停用站点的成员无法登录。

## 账号说明

| 账号 | 来源 | 说明 |
|---|---|---|
| 平台超管 `admin / admin123` | 导入数据库脚本时预置，**全系统唯一预置账号** | 登录根路径平台控制台，负责入驻审核、租户启停、隐身巡查、开放 API 密钥、数据导入导出审核等。控制台暂无平台超管改密入口，**部署后请务必直接改库换掉默认密码**（方法见常见问题 8） |
| 战队超管 | 入驻申请时由申请人自行设定 | 账号 3-20 位字母/数字/下划线（`admin` 为保留字不可用），密码 8-64 位且含字母和数字；审核通过后成为该战队超级管理员；战队主可在平台「我的站点」改其账号与密码 |
| 战队子管理员 | 战队内由超管在「管理中心 → 管理员权限分配」授权 | 按权限键细分（审核/封禁/成员名单/公告/抽奖等），未授权的管理接口一律拒绝 |
| 普通成员 | 在战队站点 `/{目录}/` 注册 | 需管理员在「注册审核」通过后才能登录；忘记密码可走申诉流程由管理员审核 |

## 安装（全新部署）

**环境要求**：PHP 8.1+（需 `pdo_mysql`、`curl`、`fileinfo`、`gd` 扩展；
启用 QQ 机器人还需 `sodium` 扩展，PHP 8.1 官方构建默认自带）、MySQL 5.7+、Nginx（或 Apache）。
依赖已随包提供（`vendor/`），**无需 composer**。

1. 上传全部代码到服务器（如 `/www/wwwroot/game-team`）。
2. **Nginx 站点根目录指向 `public/` 子目录**（不是项目根目录！），参考 `deploy/nginx.conf.example`
   （含 80→301→443、TLS、HSTS 配置；其中禁止上传目录执行 PHP 的一段务必保留）。
3. 导入数据库（**建库脚本在 `database/` 目录**）：
   - 命令行：`mysql -u root -p < database/game_team.sql`
     （脚本会自动创建 `game_team` 库并导入全部表，同时预置平台超管账号）；
   - 宝塔 / phpMyAdmin：先手工建一个 utf8mb4 的库，再导入 `database/game_team_phpmyadmin.sql`
     （无建库语句，其余内容一致）。
4. 在**项目根目录**创建 `.env` 文件（见下方「.env 配置说明」），至少填对数据库账号密码。
5. 确保以下目录可写（PHP 运行用户有写权限）：
   `runtime/`（会话/缓存/日志）、`public/storage/uploads/`（用户上传）。
6. 访问根路径，用 `admin / admin123` 登录平台控制台确认一切正常，然后**立即改库换掉默认密码**
   （控制台没有平台超管改密入口，方法见常见问题 8）。
7. （可选）本地开发可用 SQLite 免装 MySQL：`.env` 设 `DB_DRIVER = sqlite`，
   然后执行 `php scripts/dev_init_sqlite.php` 生成 `runtime/game_team.sqlite`。

> 本地调试可用内置服务器：`php think run -p 8899`（仅限开发，生产请用 Nginx）。

## 数据库文件说明

数据库本身不随代码提供，由你服务器上的 MySQL 实例承载；**建库/建表脚本都在 `database/` 目录**：

| 文件 | 用途 |
|---|---|
| `game_team.sql` | 全新安装（含 `CREATE DATABASE game_team`），命令行导入用 |
| `game_team_phpmyadmin.sql` | 全新安装（无建库语句），宝塔 / phpMyAdmin 用 |
| 各版本增量升级 SQL | 老站升级请用对应版本升级包内附带的脚本（幂等），本仓库只含全新安装用的建库脚本 |

数据库连接由 `.env` 的 `DB_*` 项决定；脚本默认建库名 `game_team`，
你也可以自建其他名字的库，把 `.env` 的 `DB_NAME` 对应改掉即可。

## .env 配置说明

项目根目录的 `.env` 控制运行环境（格式为 `键 = 值`）。模板如下：

```ini
APP_DEBUG = false
DB_DRIVER = mysql
DB_HOST = 127.0.0.1
DB_NAME = game_team
DB_USER = root
DB_PASS = 你的数据库密码
DB_PORT = 3306
DB_CHARSET = utf8mb4
DEFAULT_LANG = zh-cn
TRUSTED_PROXIES =
COOKIE_SECURE = false
```

| 配置项 | 说明 |
|---|---|
| `APP_DEBUG` | 调试开关。**生产环境务必 `false`**，排错时可临时改 `true` 看真实报错 |
| `DB_DRIVER` | `mysql`（生产）或 `sqlite`（本地开发） |
| `DB_HOST` / `DB_PORT` | 数据库地址与端口，本机默认 `127.0.0.1:3306` |
| `DB_NAME` / `DB_USER` / `DB_PASS` | 数据库名 / 账号 / 密码 |
| `DB_CHARSET` | 保持 `utf8mb4` |
| `DB_PREFIX` | 可选，表前缀，默认空 |
| `DB_SQLITE` | 可选，`DB_DRIVER = sqlite` 时的库文件路径，默认 `runtime/game_team.sqlite` |
| `DEFAULT_LANG` | 保持 `zh-cn` |
| `TRUSTED_PROXIES` | 可信代理列表（逗号分隔，支持 `/24` 网段）。服务器直连公网请**留空**；若套了反代/CDN，填其回源 IP 段，否则系统拿不到真实用户 IP（限流、封禁、注册归属地都会失真） |
| `COOKIE_SECURE` | 仅当**全站 HTTPS** 时设 `true`，为所有会话类 Cookie 启用 Secure；纯 HTTP 站点设 `true` 会导致无法登录 |

## 升级（已有站点）

1. 备份网站目录与数据库；
2. 按对应版本的热修包覆盖文件，并执行包内附带的增量 SQL（本仓库 `database/` 只有全新安装脚本）；
3. 覆盖后访问根路径确认登录页与控制台正常，再逐个功能页确认无 500。

## 重要流程说明

- **战队入驻**：申请人在根路径注册平台账号 → 提交入驻申请（选 2-30 位小写字母/数字/连字符
  的目录名、填战队名、设定战队超管账号密码、上传游戏截图证明）→ 平台超管审核通过后站点
  自动开通，地址即 `/{目录}/`。每个平台账号限入驻一个战队。
- **成员注册审核**：用户在战队站点注册后状态为"待审核"，不能登录；管理员在
  管理中心 → 注册审核 通过后才能登录（拒绝 = 删除申请，可重新注册）。
- **忘记密码**：成员在登录页点「忘记密码?」提交新密码 + 主页截图，管理员审核通过后
  新密码立即生效，旧会话全部强制下线。
- **平台超管账号**：预置 `admin / admin123` 仅存在于入驻平台（根路径）；控制台没有平台超管
  改密入口，部署后请直接改库换掉默认密码（见常见问题 8）。战队站点内没有预置账号，
  战队超管由入驻申请人自行设定。
- **数据存储**：每个租户有独立存储配额（默认 2GB），上传图片计入本队配额。
- **QQ 机器人（v5.8.0）**：平台超管在根路径控制台「QQ机器人」填入 QQ 开放平台
  （bot.q.qq.com）的 AppID/AppSecret 并启用，把页面给出的回调地址
  `https://你的域名/api/bot/callback` 填到机器人后台「消息推送 → Webhook」。
  之后走**两级绑定**：① 群绑定——群管理员在群里 @机器人 发「绑定」获取 6 位验证码
  （10 分钟有效），战队管理员在管理中心回填完成（一队一群）；② 成员绑定——成员在
  个人中心取 6 位码，群内 @机器人 发「绑定 六位码」（QQ 官方机器人拿不到 QQ 号，
  签到等个人功能靠此映射）。绑定后群内 @机器人 可：签到 / 地图（今日轮换）/
  改枪码 / 日程 / 训练赛 / 撞车 / 值班 / 伪军 名字 / 帮助；机器人出站消息统一过
  敏感词屏蔽（命中打码为星井号，词库可在平台配置扩充）。

## 常见问题

**1. 登录提示"服务器响应异常"？**
后端报错了。`.env` 把 `APP_DEBUG` 改为 `true` 再试，页面会显示真实错误；修好后改回 `false`。

**2. 撞车页时钟不准？**
页面时钟已与服务器时间校准；浏览器标签页长时间挂后台可能有轻微偏差，刷新即可。

**3. QQ 头像显示不出来？**
系统使用第三方接口 `q1.qlogo.cn`，加载失败会自动回退为文字头像；确认服务器能访问外网。

**4. 套了 CDN / 反代后，注册 IP 与归属地不对、限流异常？**
把 CDN/反代的回源 IP 段填进 `.env` 的 `TRUSTED_PROXIES`，并确保回源带 `X-Forwarded-For`；
直连部署则保持留空。同时记得在 CDN 上开「强制 HTTPS 跳转」。

**5. 开了 `COOKIE_SECURE = true` 后登录不上？**
该选项要求全站 HTTPS（浏览器只对 HTTPS 连接接受 Secure Cookie）。先完成 HTTPS 改造再开启；
临时回退可改回 `false`。

**6. 注册/找回密码提示"操作过于频繁"？**
属正常防护：注册同 IP 每小时限 3 次、同战队每天限 30 次，找回密码同 IP 每小时限 3 次；
登录连续失败还会触发账号锁定（15 分钟内失败 10 次锁 30 分钟）。

**7. 升级 v5.7.1 后，子管理员看不到成员管理？**
管理端接口已按最小权限收紧：请到 管理中心 → 管理员权限分配 给该管理员勾选
「查看成员名单」（或审核/封禁等任一成员管理权限）；管理日志现仅超级管理员可见。

**8. 平台超管 `admin` 怎么改密码？**
控制台没有平台超管改密入口，需直接改库：先在服务器执行
`php -r "echo password_hash('你的新密码', PASSWORD_DEFAULT), PHP_EOL;"`
生成哈希，再执行
`UPDATE platform_users SET password='生成的哈希' WHERE username='admin';`。
建议部署完成后立即执行，避免默认密码被人惦记。

**9. QQ 机器人在群里 @ 了没反应？**
按顺序排查：① 平台控制台「QQ机器人」是否已填凭据并启用（点「测试连接」验证）；
② 机器人后台「消息推送 → Webhook」的回调地址是否保存成功（保存时 QQ 会向
`/api/bot/callback` 发验证请求，失败说明凭据没配好或站点不可达）；
③ 事件是否勾选「群聊 @机器人」，机器人是否开启了群聊收发能力；
④ 该群是否已绑定战队（管理中心 → QQ机器人，未绑定时机器人只会回复绑定引导）；
⑤ 套了 CDN 时确认可疑拦截：`runtime/bot/` 日志有收到的事件即为推送正常，
问题多在发送侧（看日志里的 `send_fail`）。

## 安全说明

- 密码 bcrypt 哈希；全部 SQL 走 PDO 预处理；接口级登录/管理员双中间件
- 图片上传三重校验（扩展名 + 声明 MIME + 服务端真实内容）
- 前端全部转义输出防 XSS；生产环境请将 `APP_DEBUG` 设为 `false`
- v5.7.1 安全加固（17 项审计发现全部修复）：登录会话轮换、改密强制踢旧会话（密码纪元）、
  注册/入驻/找回密码限流、账号维度爆破锁定、弱口令黑名单、登录失败统一文案防枚举、
  管理端接口最小权限守卫、CSRF 全局校验、隐身巡查令牌一次性兑票、Cookie Secure 开关、
  会话 Cookie 按租户 ID 隔离、新增「忘记密码」申诉审核流程。
- v5.8.0 QQ 机器人：回调接口无登录态，安全靠 ed25519 配置验证（持 AppSecret 才能通过
  QQ 后台校验）、事件 ID 去重、「已绑定群才受理」三重机制；AppSecret 打码回显、
  出站消息敏感词打码、每群每分钟 30 条指令限流、租户停用即停服。

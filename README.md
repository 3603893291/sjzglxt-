# 三角洲行动胜者为王战队管理系统

基于 **ThinkPHP 8 + PHP 8.1 + Nginx + MySQL 5.7** 的游戏战队管理系统（部分内容由AI生成）

## 功能一览

| 角色 | 功能 |
|---|---|
| 访客 | 打开即登录页，可切换注册（QQ 号注册 + 游戏主页截图上传），或走「忘记密码」申诉（QQ 号 + 新密码 + 主页截图，管理员审核） |
| 普通用户 | **仪表盘**（注册/在线人数、公告未读提醒、今日值班与换班）、游戏图片浏览/上传（待审核）、聊天室、改枪码（发布/上下架/修改自己的）、战队小队（自由加入/退出）、撞车比赛（时间点+毫秒时钟）、**统一日程**（今日/本周：撞车/自建房/约战/赛事/活动/值班，已结束自动隐藏）、**队内训练赛**（小队对抗/自由分组，双Ban抽签/随机图）、**轻量投票**、**幸运转盘**（管理员发放机会后抽奖，奖池概率公示+中奖记录）、个人中心（改昵称/密码）、QQ 头像 |
| 管理员 | 以上全部 + 管理中心：**注册审核**（含截图/注册IP/归属地/**黑名单预警**/**忘记密码申请审核**）、用户管理（封禁/**禁言**/权限组/删除）、战队小队管理、**公告管理**（最多展示5条，文字+图片，**送达回执+一键提醒**）、**撞车时间**（最多3场）、图片审核、聊天**撤回消息/全员禁言**、改枪码（修改/下架任何人的）、**日程管理**（自定义活动/类别隐藏）、**值班表**（按天/按周轮换+换班审批）、**黑名单**、**投票管理**、**训练赛管理**（管理员发起，成员仅报名参与）、**抽奖管理**（多奖池/多奖品/权重概率/库存/机会发放/中奖核销）、**约战删除**（已过期/已完赛/部分录分约战） |

## 重要流程说明

- **注册审核**：用户注册后状态为"待审核"，不能登录；管理员在 管理中心 → 注册审核 通过后才能登录（拒绝 = 删除申请，可重新注册）
- **管理员账号**：预置（默认） `admin / admin123` 不受 QQ 号规则限制，**登录后请立即修改密码**（个人中心 → 修改密码）

## 常见问题

**1. 登录提示"服务器响应异常"？**
后端报错了。`.env` 把 `APP_DEBUG` 改为 `true` 再试，页面会显示真实错误；修好后改回 `false`。

**3. 撞车页时钟不准？**
页面时钟已与服务器时间校准；浏览器标签页长时间挂后台可能有轻微偏差，刷新即可。

**4. QQ 头像显示不出来？**
系统使用第三方接口 `q1.qlogo.cn`，加载失败会自动回退为文字头像；确认服务器能访问外网。

## 安全说明

- 密码 bcrypt 哈希；全部 SQL 走 PDO 预处理；接口级登录/管理员双中间件
- 图片上传三重校验（扩展名 + 声明 MIME + 服务端真实内容）
- 前端全部转义输出防 XSS；生产环境请将 `APP_DEBUG` 设为 `false`
- v5.7.1 安全加固（17 项审计发现全部修复）：登录会话轮换、改密强制踢旧会话（密码纪元）、
  注册/入驻/找回密码限流、账号维度爆破锁定、弱口令黑名单、登录失败统一文案防枚举、
  管理端接口最小权限守卫、CSRF 全局校验、隐身巡查令牌一次性兑票、Cookie Secure 开关、
  会话 Cookie 按租户 ID 隔离、新增「忘记密码」申诉审核流程；详见 FIXES.md
